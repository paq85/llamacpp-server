How it works
cost_per_hour = (power_W / 1000) × energy_cost_$
request_time = prompt_tokens / prompt_speed + output_tokens / decode_speed
cost_per_request = request_time / 3600 × (power_W / 1000) × energy_cost_$
cost_per_1K_prompt = (1000 / prompt_speed) / 3600 × (power_W / 1000) × energy_cost_$
cost_per_1K_output = (1000 / decode_speed) / 3600 × (power_W / 1000) × energy_cost_$
daily_cost = cost_per_request × requests_per_day
monthly_cost = daily_cost × 30

Assumes the PC draws a constant power_W while processing. In reality, idle power is lower — this is a worst-case estimate for active inference time. For a more accurate daily cost, multiply by the fraction of time the server is actually processing.
